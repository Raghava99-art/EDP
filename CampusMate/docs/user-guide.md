# User Guide

1. Start the FastAPI backend.
2. Start the React frontend.
3. Choose a category or leave the category filter on All topics.
4. Enter a question in the chat box and press Send.
5. Review the answer and related FAQ matches.
6. Use the feedback buttons to rate the answer.

If the chatbot is unsure, check the official college website or contact the relevant office. Similarity scores are not probabilities.
